# 照顧 neko

透過 shell 執行 `neko-core`。若已設定 `NEKO_CORE`，使用該執行檔；在 neko 專案中也可直接用 `.venv/bin/neko-core`。若找不到核心，請說明可在 neko 專案執行 `make venv`，再把 `NEKO_CORE` 指向該執行檔的絕對路徑。沿用目前的 `NEKO_STATE` 或核心預設存檔。

| 使用者想做什麼 | 傳給核心的參數 |
|---|---|
| 看看貓、問餓不餓或心情如何 | `status` |
| 餵乾糧、濕食、零食 | 分別用 `feed dry`、`feed wet`、`feed treat`，有指定克數才附上數字 |
| 摸摸、丟球 | 分別用 `pet`、`play` |
| 看最近的紀錄 | `log`，可附筆數（1 到 60） |
| 改名 | `rename`，把完整名字作為一個正確引用的參數傳入 |

使用者說「貓貓呢」、「看看貓」或要求看畫面時，執行本技能目錄相對位置的 `sh ../../bin/neko-codex portrait`（請用技能檔所在位置解析腳本的絕對路徑，保留目前工作目錄）。把整張像素圖放進回覆的等寬程式碼區塊，保留每行開頭的空格，再附上名字與狀態。若渲染器回報錯誤，轉述原因。

做完動作用同一次核心回傳的 `message` 和 `cat` 描述結果。餵食、摸摸、玩球成功後，分別用同一個腳本執行 `act eat`、`act pet`、`act play`，讓常駐動畫跟著反應。這些動作只更新畫面，餵食仍只執行一次。如果核心回報 `error`，直接轉述原因。
